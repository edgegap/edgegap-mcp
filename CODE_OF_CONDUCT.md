# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and discriminatory language aren't accepted in issues, pull requests or any other project space.

To report a problem, contact the maintainers privately through the repository's **Security** tab (**Report a vulnerability**) and say it's a conduct report. It will be read only by the maintainers and handled confidentially. Maintainers may remove content, or block people, who don't follow this code.
